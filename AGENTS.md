# Colaboración entre ChatGPT, Claude y el equipo Chely

Si vas a modificar este repositorio, consultá primero `docs/REGISTRO_CAMBIOS_COLABORATIVO.md`.

Reglas de trabajo:
1. Conservá la autoría de los bloques existentes. En cada sección o archivo que cambies, dejá un comentario interno como `Hecho por Claude · AAAA-MM-DD · motivo` o `Hecho por ChatGPT · AAAA-MM-DD · motivo`.
2. Agregá una entrada en el registro de cambios describiendo **qué hiciste realmente**, dónde y por qué.
3. Identificá tus commits y pull requests con la misma autoría. No se necesita mostrar etiquetas de autoría en la web pública.
4. Antes de cambios significativos, verificá la última versión de `main` y evitá pisar cambios ajenos.
5. Priorizá privacidad, accesibilidad y pruebas: Chely maneja información médica sensible.
